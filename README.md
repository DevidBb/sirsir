# JARVIS — персональный ИИ-ассистент для Windows 10/11

Два режима, одно ядро (`jarvis/assistant.py`, реестр инструментов, память, подтверждения):

* **Интерфейс HUD в браузере** (`run_web.bat`): чат с потоковым
  выводом, ход задачи, результаты поиска, память, настройки, диагностика. Джарвис управляет
  **своим** браузером (Playwright, отдельный профиль): ищет в интернете и на YouTube, открывает
  результаты, читает страницы, нажимает кнопки, заполняет поля, переключает вкладки.
  Модели — Ollama Cloud, ChatGPT через Codex, Gemini, Claude и локальная Ollama: вместе или по отдельности.
* **Голосовой режим** (`run.bat`, Windows): фраза пробуждения (Vosk), распознавание речи
  (faster-whisper), ответы (Ollama + qwen3:8b), озвучка (Silero или голоса Windows) — всё локально.

Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Что сделано и что дальше:
[docs/ROADMAP.md](docs/ROADMAP.md).

## Интерфейс HUD: быстрый старт

`install.bat` (ставит и Chromium, по желанию — Claude), затем `run_web.bat` — HUD **вместе с локальным
голосом**: скажите «Джарвис» или нажмите «Слушать»; распознанная фраза, ход задачи и ответ видны в HUD,
ответ звучит голосом Silero/Windows. Кнопка микрофона выключает и включает микрофон, «Прервать речь»
обрывает ответ, «Стоп» — задачу. Звук обрабатывается только на компьютере. Без голоса:
`run_web.bat --no-voice`. Микрофон выбирается и проверяется во вкладке «Система → Звук»
(список устройств, уровень сигнала в реальном времени, проверка записи и голоса). Если моделей речи или микрофона нет, HUD сообщит об этом и будет
работать как чат.

Как устроен экран: в центре — «глаз» Джарвиса со сферой из светящихся точек. Он показывает
состояние (ждёт, слушает, думает, выполняет, говорит); сфера дышит в такт настоящему звуку —
уровню микрофона или голосу Silero, а если сигнала нет (системный голос Windows), показывает
ровную анимацию состояния и подписывает это. Щелчок по глазу — то же, что «Слушать». Слева —
приветствие, крупно — что Джарвис делает сейчас, ниже — разговор (он сохраняется при обновлении
страницы). Под глазом — карточка «Нужно ваше решение» с кнопками «Подтвердить»/«Отклонить», поле
ввода и быстрые команды. Справа — короткая панель «Память» (что из памяти ушло модели в последней
задаче, связанные заметки, последние решения и следующие шаги), ниже — «Шаги» (какая модель
отвечает и почему, какие инструменты работают), «Результаты», «Память», «Расписание», «Система». Вверху —
переключатель модели (Гибрид / Ollama / Claude / Gemini), загрузка процессора, памяти и видеокарты (настоящие
значения), часы, кнопка обновления и смена темы: красная «Ядро» или синяя «Марк».

Вручную: `pip install -r requirements.txt`, `python -m playwright install chromium`,
`python -m jarvis --web` (`--voice` — с локальным голосом, `--no-open` — не открывать страницу).

Что можно написать (или сказать кнопкой микрофона в Chrome/Edge):

| Команда | Что происходит |
|---|---|
| «Открой YouTube и найди видео про локальных ИИ-ассистентов» | настоящий поиск на YouTube в браузере Джарвиса; карточки: название, канал, длительность, просмотры, дата |
| «Открой второе видео» / кнопка «открыть у Джарвиса» | открывает выбранное видео |
| «Найди в интернете …», «загугли …», «search the web for …» | DuckDuckGo (запасной — Bing) через браузер, без API-ключей; список источников со ссылками |
| «Найди, что такое MCP, открой два источника и сравни» | сложная задача → модель: план, поиск, чтение страниц, вывод со ссылками |
| «Открой en.wikipedia.org, найди через поиск статью X и скажи …» | последовательность браузерных действий с проверкой каждого шага |
| «Посмотри на экран и объясни, что за ошибка» | снимок экрана → модель с поддержкой изображений (Claude, Gemini или `[llm] vision_model` в Ollama); снимок виден в чате |
| «Сделай скриншот экрана» | сохраняет снимок в `data/screenshots` и показывает его |
| «Запомни, что я предпочитаю короткие ответы» | предпочтение в локальной памяти (SQLite) — модель будет его соблюдать; «запомни, меня зовут …» — факт. Поиск, правка, удаление — вкладка «Память» |
| «Запиши решение: сферу пишем на WebGL», «следующий шаг — …», «запиши результат проверки: …» | заметка Obsidian (Markdown) в `data/obsidian` — без модели; видна в панели «Память» |

Простые команды (открыть сайт, поиск на YouTube/в интернете, «открой третий результат»,
калькулятор, таймеры, заметки) выполняются **без модели** — мгновенно и бесплатно.
Многошаговые просьбы («сравни», «прочитай», «потом», «дай вывод») уходят модели.

**Модель** (Настройки → Модель, или `[llm] provider` в `config.toml`):

* `team` — режим по умолчанию: все подключённые участники отвечают параллельно, ведущий сверяет
  ответы и даёт общий итог. Уточнения получают контекст недавнего диалога. Быстрые команды выполняются
  локально; обсуждение команды не выполняет действия в приложениях. Навыки с инструментами работают
  через обычный цикл Ollama. Сбой или лимит одного участника не прерывает остальных; «стоп» отменяет
  обсуждение, включая подготовку итога. Ответы каждого видны во вкладке «Проекты».
* `codex` — ответы только ChatGPT через Codex CLI; быстрые команды остаются локальными.
  Установка в терминале: `npm install -g @openai/codex`, затем `codex login`.
* `ollama_cloud` — облачные модели Ollama через официальный API, с теми же инструментами,
  что у локальной Ollama. Нужен `OLLAMA_API_KEY` в `.env`.
  Модель выбирается в `[llm.ollama_cloud] model`; имя берётся из
  [списка API](https://ollama.com/api/tags), без суффикса `:cloud`.
* `hybrid` — режим по умолчанию: быстрые команды выполняются без LLM; короткие обычные вопросы — локально через Ollama; сложные многошаговые и актуальные запросы — через Claude, если SDK доступен. При отсутствии SDK используется локальная модель.
  Claude получает: свежие данные (погода, новости, цены, курсы, результаты матчей, «когда выйдет»,
  «сейчас» о мире), многошаговые задачи («найди … и скажи/выбери», действия на сайтах, «эта
  страница», файлы проекта, «закажи», «и отправь…»), длинный разбор (сравнение, анализ, план, код,
  «подробно»). Всё остальное — разговор, определения, переводы, короткие тексты — локально.
  Продолжение («а подробнее?», «давай ещё», «а послезавтра?») идёт той же модели, что ответила
  перед этим. Кто отвечает и почему — видно в «Ходе задачи». Таблица маршрутов на 111 фразах:
  `python scripts\benchmark_routing.py` (с `--live` — настоящие ответы и время на вашем ПК).
* `ollama` — полностью локальные ответы модели. Нужна запущенная Ollama и модель из `[llm] model`.
* `claude` — Claude Agent SDK для запросов к модели: `pip install -r requirements-claude.txt` и вход `claude login`
  (подписка Claude) или `ANTHROPIC_API_KEY` в `.env`. **Запрос, результаты инструментов и текст
  прочитанных страниц отправляются в облако Anthropic.** Встроенные инструменты Claude Code
  (shell, файлы, веб) отключены, пользовательские настройки и плагины не загружаются — модели
  доступны только инструменты Джарвиса с теми же проверками и подтверждениями.
  При выборе `hybrid` локальные быстрые команды остаются локальными, но сложные вопросы и содержимое
  прочитанных страниц могут отправляться в Anthropic. Если Claude настроен, JARVIS заранее запускает
  его клиент в фоне, чтобы сократить задержку первого сложного запроса.
* `gemini` — Gemini (облако Google) вместо Ollama: те же инструменты, проверки и подтверждения, что у
  локальной модели. Нужен бесплатный ключ (https://aistudio.google.com/apikey) в `.env`:
  `GEMINI_API_KEY=...`. Модель — `[llm.gemini] model` (по умолчанию `gemini-3.6-flash`; если она
  перегружена — запасная `fallback_model`); понимает и снимки экрана. **Запрос и результаты инструментов отправляются в Google.**
  У бесплатного тарифа есть дневные лимиты — при превышении Джарвис так и скажет.

Если вы обновляете существующую установку, ранее сохранённый выбор модели в `data/memory.db`
имеет приоритет над значением по умолчанию в `config.toml`. При необходимости выберите
**Гибрид (Ollama + Claude)** через HUD → Настройки → Модель.

**Экран:** снимок всего экрана делается только по вашей прямой просьбе («посмотри на экран»). У модели нет
инструмента, который сам показывает ей экран, поэтому текст с веб-страницы не может заставить Джарвиса
отправить ваш экран в облако. Снимки страниц **браузера Джарвиса** модель видит (это помогает, когда текста
страницы недостаточно).

**Стоп:** кнопка «Стоп» или Esc прерывает задачу (браузерное действие, генерацию, агента) за 1–3 с.
**Подтверждения:** нажатие кнопок вроде «Купить», «Отправить», «Удалить», ввод в поле пароля,
отправка текста из многострочного поля, удаление файлов и т.п. требуют кнопки «Подтвердить».

**Голос в HUD без `--voice`:** кнопка микрофона использует распознавание браузера (Web Speech API). В Chrome/Edge
**звук обрабатывается сервисом Google** (облако); в Firefox этой функции нет. Озвучка ответов —
голоса системы (`speechSynthesis`), «Прервать речь» — остановить. Полностью локальный голос —
голосовой режим (`run.bat`).

**Что уходит в интернет в режиме HUD:** запросы поиска и открытые страницы — из браузера Джарвиса
(как при обычном сёрфинге); при `provider = "claude"` — диалог с моделью. Процесс Python сам в
интернет не ходит (сетевой фильтр, только localhost). Сервер HUD слушает только 127.0.0.1 и
принимает запросы только со своей страницы (проверка Origin/Host).

Целевое железо: i5-10400F, RTX 3060 12 ГБ, 16 ГБ ОЗУ.

## Навыки, файлы и внешние инструменты

- **Навыки** — готовые сценарии в `skills/`: `research` («сравни источники: …»), `project-review`
  («проверь проект»), `video-pick` («подбери видео про …»). Можно сказать «навык research …».
  Свой навык — папка `skills/<имя>/SKILL.md`:
  ```
  ---
  name: my-skill
  description: Что делает навык (видит модель).
  triggers: ["фраза запуска"]
  tools: [internet_search, read_page, "files_*"]   # пусто — все инструменты
  max_steps: 8
  ---
  Пошаговая инструкция для модели.
  ```
  После правки — HUD → Настройки → Навыки → «перечитать».
- **Расписание** — HUD → «Расписание» (или «каждый будний день в 9 утра делай сводку новостей»):
  каждый день, по будням/выходным, по дням недели, каждые N минут (от 15) или один раз. Итог — в чате
  и журнале запусков. Действия с подтверждением в плановой задаче не выполняются.
- **Поручения агентам** (с Claude) — «сравни Rust, Go и Zig» — каждую часть исследует отдельный агент,
  параллельно; агенты только читают (поиск, страницы, разрешённые файлы). Отключить —
  `[llm.claude] delegate = false`; дешевле — `agent_model = "haiku"`.
- **Файлы и проекты** — `[files] allowed_dirs` в `config.toml`; изменения только после diff и подтверждения.
- **Внешние MCP-серверы** — `[mcp.servers.<имя>]` в `config.toml` с белым списком инструментов.

## Память в Obsidian

Проекты, цели, задачи и следующие шаги, решения и результаты проверок Джарвис хранит обычными
файлами Markdown в `data/obsidian` (`[memory.vault] path` — можно указать своё хранилище Obsidian).
Откройте эту папку в Obsidian как хранилище (vault) — заметки можно читать и править там, Джарвис
подхватит правки перед следующей задачей. Кнопка «Obsidian» в панели «Память» и вкладка «Память →
Заметки Obsidian» открывают указатель `INDEX.md`; там же — «Пересобрать указатель».

* У каждой записи один владелец. Файлы хранилища владеют проектными заметками; в SQLite — только
  индекс для поиска. Факты, предпочтения и итоги задач хранит `memory.db`, а в папке `Джарвис/` лежит
  их копия только для чтения (правку в ней Джарвис не потеряет — положит рядом копией «…-правка-<дата>.md»).
* Заметка — frontmatter (`type`, `status`, `date`, `project`, `topic`, `source`…), текст и строка
  `Related:` с обычными markdown-ссылками: файлы читаются и в Obsidian, и на GitHub, и в любом редакторе.
  Статус отличает проверенный факт от предположения, плана и сделанного; новое решение на ту же тему
  помечает старое «заменено».
* Найденные по запросу заметки уходят модели вместе с фактами; что именно ушло — видно в панели «Память».
* Пароли, ключи и номера карт в заметки не записываются и не индексируются.
* Выключить — `[memory.vault] enabled = false`.

## Студия сайтов и команда ИИ

- **Студия сайтов** — «Джарвис, сделай новый сайт для кофейни Зерно» или «переделай сайт example.ru».
  Джарвис находит текущий сайт бренда, разбирает его в своём браузере (товары с ценами, логотип,
  фирменные цвета, контакты), пишет тексты выбранной моделью, верстает один `index.html` для компьютера и
  телефона и показывает оценки «было → стало» (SEO, мобильная версия, доступность, вес). Цены, телефоны и
  адреса берутся только со старого сайта или из вашей просьбы. Правки голосом: «измени сайт: сделай тёмную
  тему», «переведи сайт на английский». Ход работы — вкладка «Проекты». Сайты лежат в `data/sites/<имя>`.
- **Команда ИИ** — «спроси всех: какой ноутбук взять для монтажа», «обсудите командой: стоит ли открывать
  вторую точку». Вопрос уходит сразу всем доступным ИИ: Claude, ChatGPT (через Codex CLI), Gemini, Ollama Cloud и
  локальной модели. Они отвечают параллельно, потом ведущий (самый сильный из ответивших) сверяет ответы
  и говорит один итог: в чём сошлись, кто ошибся, где разошлись. Во вкладке «Проекты» видно ответ каждого
  и сколько он думал. Участники только пишут текст — браузером и файлами управлять не могут.
  Как подключить участников:
  - Claude — `install.bat` с Claude SDK и вход в claude.ai (как для режима Claude);
  - ChatGPT — `npm install -g @openai/codex`, затем `codex login` (вход по подписке ChatGPT);
  - Gemini — бесплатный ключ `GEMINI_API_KEY` в `.env`;
  - Ollama Cloud — ключ `OLLAMA_API_KEY` в `.env` ([создать ключ](https://ollama.com/settings/keys));
  - локальная модель — запущенная Ollama и скачанная модель из `[llm] model`.
  Состав и ведущий — `[team]` в `config.toml`. Облачные участники получают вопрос через интернет.
  Если участник не настроен, остальные продолжают работать. Наличие ключа или CLI в настройках
  означает готовность к попытке подключения; успешный вход и доступность проверяются самим запросом.
  В режиме «Команда» новые сайты также получают проверку команды.

Для подключения облаков на Windows откройте **терминал в папке Джарвиса** и выполните:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

В открывшемся **Блокноте** добавьте свои значения (без `#` в начале строк):

```dotenv
GEMINI_API_KEY=ваш_ключ_Gemini
OLLAMA_API_KEY=ваш_ключ_Ollama
```

Сохраните файл сочетанием **Ctrl+S**, закройте Блокнот и перезапустите Джарвиса.
В HUD выберите **«Команда»**; эта настройка сохраняется. Личные ключи остаются в `.env`, который не входит в git.
Если ранее выбирали другой режим, сохранённая настройка имеет приоритет над новым значением по умолчанию.
Протоколы подключения: [Ollama Cloud](https://docs.ollama.com/cloud),
[Codex CLI](https://developers.openai.com/codex/noninteractive/),
[Gemini API](https://ai.google.dev/gemini-api/docs/openai).

## Как это работает

```
микрофон ─► wake_word (Vosk, «Джарвис») ─► audio_input (запись до паузы, VAD)
        ─► speech_recognition (Whisper small, GPU → CPU) ─► assistant
        ─► llm (Ollama localhost) ⇄ tool_registry ─► windows_control / memory
        ─► text_to_speech (SAPI5) ─► динамики
```

| Модуль | Назначение |
|---|---|
| `jarvis/wake_word.py` | ожидание «Джарвис» (Vosk с грамматикой из одного слова, CPU) |
| `jarvis/audio_input.py` | захват с микрофона в память, определение конца речи |
| `jarvis/speech_recognition.py` | faster-whisper `small`, откат на CPU при ошибке GPU |
| `jarvis/llm.py` | клиент Ollama (только localhost), ограниченная история |
| `jarvis/tool_registry.py` | реестр разрешённых действий и проверка аргументов |
| `jarvis/windows_control.py` | приложения, сайты, папки и файлы, поиск файлов, системная информация, окна |
| `jarvis/app_finder.py`, `jarvis/fuzzy.py` | поиск программ по ярлыкам меню «Пуск», адреса сайтов, нечёткое сравнение названий |
| `jarvis/memory.py` | SQLite: факты о пользователе и голосовые настройки |
| `jarvis/vault.py` | заметки Obsidian: проекты, решения, проверки, шаги — файлами Markdown; копия memory.db только для чтения |
| `jarvis/text_to_speech.py` | озвучка (Silero или SAPI5), прерываемая между предложениями |

## Установка (Windows)

**Быстрый способ:** установите Python 3.11+ и Ollama, затем запустите `install.bat`.
Скрипт создаст окружение, поставит зависимости, скачает модели (спросив подтверждение) и проверит всё.
Запуск помощника: `run.bat`, текстовый режим: `run_text.bat`.

**Вручную:**

1. **Python 3.11+** с python.org (галочка «Add to PATH»).
2. **Ollama** с ollama.com, затем модель (~5.2 ГБ, около 6 ГБ VRAM):
   ```
   ollama pull qwen3:8b
   ```
3. Зависимости (~1.5 ГБ вместе с библиотеками CUDA для Whisper):
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Модели речи, около 520 МБ (Vosk ~45 МБ + Whisper small ~470 МБ). Скрипт покажет размеры и спросит подтверждение:
   ```
   python scripts\download_models.py
   ```
5. Голос, один из двух вариантов:
   - **Silero v5** (естественный нейросетевой голос: torch для CPU ~200 МБ и модель голоса):
     ```
     pip install -r requirements-silero.txt --index-url https://download.pytorch.org/whl/cpu --extra-index-url https://pypi.org/simple
     python scripts\download_models.py --only-silero
     ```
     Работает на CPU и не занимает видеопамять. Первый ответ готов примерно через 0,4 с.
     Голоса: aidar, eugene (мужские), baya, kseniya, xenia (женские) — `tts.silero_speaker`.
     Послушать все и выбрать: `voices.bat`. Голосом: «смени голос», «женский голос», «голос бая».
     Если раньше стояла модель v4: `python scripts\download_models.py --only-silero` докачает v5
     (до этого помощник продолжит говорить голосом v4).
   - **Системный**: *Параметры → Время и язык → Речь → Добавить голоса → Русский*.

   В режиме `tts.engine = "auto"` (по умолчанию) используется Silero, если он установлен, иначе системный голос.

Память: Whisper small на GPU занимает около 1 ГБ, qwen3:8b около 6 ГБ, то есть 12 ГБ VRAM хватает с запасом.
Если GPU недоступен, Whisper автоматически работает на CPU (int8). Это заметно медленнее:
на машине разработки около 4–5 с на фразу, на i5-10400F ожидается около 2–2,5 с.
Можно поставить `speech_recognition.model = "base"`: втрое быстрее, но ошибок вдвое больше
(замер на 36 фразах: small — 12% ошибок слов, base — 26%, tiny — 30%).
Ollama выгружает модель из VRAM после 5 минут простоя (`llm.keep_alive`).

## Обновление

`update.bat` — одна команда вместо `git pull` + `pip install`:

* свои правки `config.toml` переносит в **`config.local.toml`** (он не в git и применяется поверх
  `config.toml`), а `config.toml` возвращает к версии из репозитория — конфликтов при обновлении нет;
  копия прежнего файла остаётся в `data\config.toml.<дата>.bak`;
* скачивает новую версию (`git fetch`, только fast-forward) и показывает список изменений;
* если поменялись `requirements*.txt` — доустанавливает пакеты и Chromium (Claude SDK и Silero —
  только если они уже стоят).

Другие изменённые файлы и локальные коммиты, которых нет на сервере, обновление не трогает:
оно остановится и назовёт их. Перед обновлением закройте Джарвиса. Нужен Git for Windows и
установка через `git clone`.

**Из HUD.** Джарвис сам проверяет обновления (только `git fetch`, без окон входа) при запуске и
раз в 6 часов (`[update]` в `config.toml`). Когда они есть, вверху появляется кнопка
«Обновление · N»: список изменений и «Обновить и перезапустить». Джарвис закроется, обновится
(то же, что `update.bat`) и запустится снова, страница HUD переподключится сама, а в чате будет
итог. Перезапуск из HUD работает при запуске через `run_web.bat`; версия и состояние проверки —
во вкладке «Диагностика».

Свои настройки можно сразу писать в `config.local.toml` — только то, что отличается, например:

```toml
[files]
allowed_dirs = ["D:/Projects"]
```

## Запуск

Сначала выберите и проверьте микрофон: `setup_mic.bat` (или `python -m jarvis --setup-mic`).
Мастер покажет уровни шума и речи, проверит, слышит ли помощник «Джарвис» и что распознаёт,
и запомнит выбранный микрофон.

```
python scripts\check_components.py          # проверить всё
python scripts\check_components.py --live   # плюс реальные пробы LLM, голоса и микрофона
python -m jarvis                            # голосовой режим
python -m jarvis --text                     # текстовый режим (без микрофона), удобно для отладки
```

```
run_web.bat --tray                          # HUD с голосом и значком-глазом в трее
python -m jarvis --tray                     # только голос, со значком в трее
python -m jarvis --autostart on             # запускать при входе в Windows (off — выключить)
```

**Запуск при входе в Windows** — переключатель в HUD («Система → Запуск») или `--autostart on`.
В папку «Автозагрузка» пользователя кладётся `JARVIS.cmd` (права администратора не нужны): он
запускает HUD с голосом свёрнутым, со значком в трее и без новой вкладки браузера.

Значок HUD в трее — глаз: красный — готов, зелёный — слушает, янтарный — думает или выполняет,
светлый — говорит, серый — микрофон выключен. Щелчок открывает HUD; в меню — микрофон, «Остановить»
и «Выход»; напоминания приходят уведомлением Windows, даже когда HUD закрыт.
Значок голосового режима (`--tray` без HUD): синий — ждёт «Джарвис», зелёный — слушает,
оранжевый — говорит, серый — микрофон выключен; щелчок включает и выключает микрофон.

В окне программы: **Enter** включает и выключает микрофон, **s + Enter** даёт аварийную остановку, **q + Enter** завершает работу.

## Голосовые команды

- «Джарвис» → короткий сигнал → команда. Можно говорить одной фразой: «Джарвис, открой блокнот».
  После ответа примерно 8 секунд можно продолжать без повторного «Джарвис».
- «Стоп», «хватит», «замолчи»: перебить помощника, пока он говорит.
- Ответы модели звучат по предложениям прямо во время генерации, без ожидания всего текста.
  «Стоп» во время ответа обрывает и речь, и генерацию.
- «Отмена»: отменить текущий диалог.
- «Спасибо», «хватит», «стоп», «всё» после ответа: закончить разговор сразу, без обращения к модели
  и без ожидания продолжения. В режиме диктовки «стоп», «хватит» или «всё» завершают диктовку.
- «Стоп стоп», «Аварийная остановка», «Джарвис стоп»: немедленно остановить речь и отменить ожидающее действие.
- «Выключи микрофон»: микрофон выключается, включить его снова можно клавишей Enter.
- «Очисти память»: требует подтверждения.
- «Новый диалог»: сбросить историю беседы.
- «Заверши работу»: выход.
- Обращаться можно и так: «Привет, Джарвис, открой ютуб», «Доброе утро, Джарвис, …».
- Голос: «смени голос», «женский голос», «мужской голос», «голос бая/ксения/ксюша/айдар/евгений».
  Выбор запоминается.
- «Что ты умеешь?»: краткий список возможностей. «Повтори»: повторить последний ответ.
- Таймеры и напоминания: «поставь таймер на 5 минут», «засеки 1 минуту 30 секунд»,
  «напомни через 20 минут выключить плиту», «напомни в 18:30 забрать посылку»,
  «поставь будильник на 7:30», «какие напоминания», «отмени таймер».
  Они хранятся в базе и не пропадают при перезапуске. Пропущенные помощник озвучит при следующем запуске.
- Диктовка: «напечатай привет запятая как дела вопросительный знак» печатает фразу в активное окно.
  «Начни диктовку» печатает всё сказанное до «закончи диктовку» или 30 секунд тишины.
  Знаки препинания голосом: точка, запятая, вопросительный знак, двоеточие, тире, скобки.
- Поиск на сайтах и в приложениях: «найди на ютубе котиков», «открой ютуб и включи lofi»,
  «загугли погоду в Москве», «найди в интернете рецепт борща», «найди в википедии чёрная дыра»,
  «найди на озоне наушники», «найди на карте аптеку», «включи в спотифае рок»,
  «включи песню Imagine Dragons» (сервис для музыки — `windows.web_search.music`).
  Сайты: YouTube, Google, Яндекс, Яндекс Музыка и Карты, Википедия, ВК, Rutube, Кинопоиск,
  Авито, Озон, Wildberries, GitHub, Twitch, магазин Steam, Spotify (в установленном приложении).
  Открывается страница результатов в браузере, сам помощник страницы не загружает.
- Составные команды: «открой блокнот и напиши привет», «запусти блокнот, потом вставь».
  Помощник открывает программу, ждёт её окно и выполняет вторую часть уже в нём; если окно
  не появилось, печатать не будет.
- Печать в нужное окно: «напиши в телеграм привет, как дела» — помощник переключится на окно
  (по заголовку, «телеграм» = Telegram, «ворд» = Word) и напечатает текст. Окно должно быть открыто.
- Сочинить текст: «напиши письмо начальнику, что я заболел», «сочини поздравление маме».
  Модель составит текст, помощник зачитает начало и спросит подтверждение; после «подтверждаю»
  текст печатается в активное окно (Enter при этом не нажимается).
- Клавиши голосом: «новая строка» (Shift+Enter — перенос, сообщение не отправляется),
  «сохрани» (Ctrl+S), «отмени ввод» или «верни как было» (Ctrl+Z), «выдели всё» (Ctrl+A),
  «копировать» (Ctrl+C), «вставить» (Ctrl+V), «закрой вкладку» (Ctrl+W), «новая вкладка» (Ctrl+T).
  Просто «отмена»/«отмени» — это по-прежнему отмена диалога, а не Ctrl+Z.
  «Отправь» нажимает Enter только после «подтверждаю». В режиме диктовки «новая строка» тоже переносит строку.
- Калькулятор: «сколько будет 15 процентов от 2400», «посчитай 25 умножить на 4», «корень из 144».
  Считает точно и безопасно (разбор выражения, без выполнения кода).
- Заметки: «запиши заметку купить молоко», «прочитай заметки».
- Открыть что угодно: «открой телеграм», «запусти стим», «открой фотошоп» — любая программа,
  у которой есть ярлык в меню «Пуск» (поиск по-русски и по-английски, список ярлыков кэшируется
  на 10 минут). Сайты: «открой вконтакте», «зайди на habr.com», «открой хабр точка ком».
  Папки и файлы по имени: «открой папку отчёты», «открой файл годовой отчёт», «открой загрузки».
  Если подходит несколько вариантов, помощник перечислит их и спросит: ответьте «второй»
  или назовите вариант («экспресс»), «отмена» — ничего не открывать.
- Компьютер: «заблокируй компьютер», «переведи компьютер в сон», «выключи компьютер», «перезагрузи компьютер».
  Всё, кроме блокировки, требует подтверждения. Выключение идёт через минуту, «отмени выключение» его отменяет.
- Громкость и музыка: «погромче», «сделай звук тише», «прибавь громкость», «выключи звук»,
  «поставь музыку на паузу», «следующий трек», «предыдущая песня».
- Время: «который час», «сколько сейчас времени», «какой сегодня день недели».
- Частые команды выше разбираются без языковой модели и выполняются мгновенно; «пожалуйста»
  в любом месте фразы не мешает.
- Примеры: «открой блокнот», «открой ютуб», «открой телеграм», «найди файл отчёт», «сколько свободно памяти»,
  «сверни окно телеграм», «запомни, что меня зовут Давид», «сделай речь быстрее».

## Безопасность

- Модель **не выполняет код**: никакого Python, PowerShell или shell от LLM. Она может только попросить
  вызвать инструмент из реестра `tool_registry`. Неизвестные инструменты, лишние аргументы, неверные типы
  и управляющие символы отклоняются.
- Программы запускаются из `[windows.apps]` или **по ярлыку из меню «Пуск»**: запускается сам ярлык
  через `os.startfile`, без оболочки. Ярлык не запускается, если ведёт на скрипт (.bat, .cmd, .ps1,
  .vbs и т.п.), на программу из «Загрузок» или временной папки или на командную строку с аргументами;
  `.url`-ярлыки — только со схемами из `windows.launcher.url_schemes`.
- Сайты открываются только по `http`/`https` (`file:`, `javascript:`, `chrome:` отклоняются). В голосовом
  режиме — в системном браузере; в режиме HUD — в браузере Джарвиса с отдельным профилем
  (`data/browser-profile`): пароли и cookies вашего личного браузера не читаются.
- Текст веб-страниц и результаты поиска передаются модели как **недоверенные данные** (в обёртке
  `<untrusted>` с указанием не выполнять инструкции оттуда); правила безопасности они не меняют.
- В память не записываются пароли, токены, ключи API и номера карт (ни голосом, ни через HUD).
  Память можно скачать копией и загрузить на другом компьютере (HUD → Память → «Перенос памяти»):
  импорт только добавляет записи, плановые задачи из файла приходят выключенными, настройки
  безопасности, разрешённые папки и сеть через импорт не меняются.
- Файлы и папки открываются только из `windows.search.allowed_dirs`; программы и скрипты оттуда
  (.exe, .msi, .bat, .cmd, .ps1, .vbs, .lnk…) не открываются.
- Поиск и удаление файлов разрешены только в каталогах `windows.search.allowed_dirs`.
  Удаление идёт **в корзину**.
- Удаление файла, закрытие окна, смену настроек и очистку памяти нужно **подтвердить голосом**
  («подтверждаю»). Любой другой ответ или 20 секунд тишины отменяют действие.
- Повтор той же фразы в течение 4 секунд игнорируется. Выполняется не больше 12 действий в минуту
  и не больше 3 вызовов инструментов на реплику. Повторный одинаковый вызов прерывается как цикл.
- Диктовка печатает только распознанную речь пользователя. Текст, сочинённый моделью, печатается
  только после голосового «подтверждаю»; сама модель печатать и нажимать клавиши не может
  (этих действий нет среди её инструментов).
- Клавиши — только из белого списка (Ctrl+S/Z/A/C/V/W/T и Shift+Enter); Enter («отправь») —
  только после подтверждения. Печать в другое окно идёт, только если Windows действительно
  переключил на него фокус.
- Ни печать, ни клавиши не отправляются в окна терминалов (cmd, PowerShell, Windows Terminal).
- Во время своей речи помощник реагирует только на фразы перебивания («стоп», «хватит»).
  Остальное, включая эхо собственного голоса, отбрасывается.
- Все выполненные действия записываются в `data/actions.log` (без записи звука и без текста разговоров).
- Сетевые соединения из процесса Python разрешены только к `security.allowed_hosts` (localhost),
  загрузки Hugging Face отключены (`HF_HUB_OFFLINE=1`). В интернет ходят только отдельные процессы:
  браузер Джарвиса и, если выбран провайдер `claude`, Claude Code CLI.
- Работа с файлами и проектами («изучи проект и найди ошибки») — только в папках из `[files] allowed_dirs`
  (по умолчанию нет ни одной). Чтение, список и поиск — сразу; создать или изменить файл можно только
  после подтверждения, перед которым в HUD показан diff (на просмотр — 3 минуты). Старая версия
  копируется в `data/file-backups`; если файл изменился, пока вы смотрели diff, запись отменяется.
  Файлы с секретами (`.env`, ключи, `.kdbx`, папки `.ssh`/`.aws`) не читаются и не ищутся;
  `.exe`, `.bat`, `.ps1` и другие запускаемые файлы, а также служебные файлы `.git` не меняются.
  Символические ссылки за пределы разрешённых папок не открываются.
- Плановые задачи выполняются без пользователя, поэтому ничего, что требует подтверждения, в них не
  выполняется (модель получает отказ и пишет об этом в итоге); создать задачу голосом или через модель
  можно только с подтверждением, сама задача новую задачу не создаст. Диалог пользователя и контекст
  Claude плановая задача не трогает.
- Навыки (`skills/<имя>/SKILL.md`) — только инструкции: они могут сузить набор инструментов, но не
  расширить его и не отменить подтверждения; скрипты из папки навыка Джарвис не запускает.
- Внешние MCP-серверы (`[mcp.servers.*]` в `config.toml`) подключаются только явно: модель видит лишь
  инструменты из `allowed_tools`, без подтверждения выполняются только `auto_tools`. Сервер запускается
  без оболочки, ответы сервера — недоверенные данные. Токены — в `.env` (`env_vars` — только имена
  переменных). Сам сервер — отдельная программа со своим доступом к сети и файлам: подключайте только
  те, которым доверяете. Состояние — HUD → Диагностика, журнал — `data/mcp/<имя>.log`.
- Программа не требует прав администратора. Запускайте от обычного пользователя.
- Звук не записывается на диск. Микрофон можно физически отключить: помощник это заметит и остановится.

## Проверка речи без микрофона

```
python scripts\benchmark_speech.py
```

Голосом Silero (5 разных голосов) произносятся фразы и прогоняются через настоящие Vosk и Whisper.
Скрипт показывает, как часто срабатывает «Джарвис», бывают ли ложные срабатывания на обычной речи,
не перебивает ли помощник сам себя и как быстро идёт распознавание на этом ПК.
Результат на машине разработки (только CPU): «Джарвис» 20/20, ложных 0/50, «стоп» 12/12,
ложных перебиваний собственным голосом 0/6. Шум и тишина не дают «субтитров».

Последний раздел произносит 55 быстрых команд (время, громкость, таймеры, будильник, напоминания,
калькулятор, заметки, поиск, «открой …», клавиши) и проверяет, что после Whisper их разбирает сам
Джарвис, без модели, — с подсказкой Whisper и без неё (`[speech_recognition] hotwords`, по умолчанию
`"auto"` — «Джарвис» и русские названия сайтов из `[windows.websites]`). Разбор учитывает, как
Whisper на самом деле слышит команды: «всем вечера» (= «в семь вечера»), «от мини таймер»,
«с копируй», «ставь» (= «вставь»), «открою ютуб», «YouTube», числа словами и цифрами, падежи
(«открой почту», «говори голосом Ксении»). На машине разработки (Silero v5, 3 голоса, CPU) на тех же
расшифровках прежний разбор понимал 165 команд из 195, сейчас — 191; подсказка Whisper убирает
«гитхап». Влияние подсказки на скорость здесь измерить не удалось (CPU занят другими процессами) —
сравните строки «без подсказки» и «hotwords» на своём ПК; если подсказка заметно замедляет,
поставьте `hotwords = "Джарвис"` в `config.local.toml`.

## Проверка языковой модели

```
python scripts\benchmark_llm.py
```

16 типичных просьб без быстрых команд: видно, какой инструмент выбрала модель, сколько токенов

## Если что-то не работает

Запустите `report.bat` (или `python -m jarvis --report`). Он соберёт в `data\report.txt` версии
пакетов, версию кода (коммит), видеокарту, список микрофонов, результаты проверок, основные настройки и конец журнала
`data\jarvis.log`. Звук, заметки, память и разговоры в отчёт не попадают. Проверьте файл и пришлите его.

## Тесты

```
pip install -r requirements-dev.txt
python -m pytest            # все тесты; без сети
python -m pyflakes jarvis scripts tests
```

`tests/test_browser_real.py` запускает настоящий Chromium на локальной тестовой странице
(пропускается, если Chromium для Playwright не скачан). `tests/test_web_app.py` проверяет сервер HUD
(Origin/Host, WebSocket, отмена, память), `tests/test_providers.py` — Claude Agent SDK с подставным
клиентом. CI на настоящей Windows: `.github/workflows/windows.yml` и `windows-install.yml`.

Проверки на настоящих моделях (Silero → Vosk/Whisper, Ollama), идут несколько минут:

```
set JARVIS_REAL_TESTS=1
python -m pytest tests\test_real_models.py -v
```

Обычные тесты не требуют Ollama, микрофона и моделей: LLM, окна и корзина заменены фейками.
Тестами покрыты безопасность, реестр, управление Windows, память, клиент Ollama
(через локальный фейковый сервер), определение конца речи и логика диалога.
