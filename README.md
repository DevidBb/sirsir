# JARVIS — локальный голосовой помощник для Windows 10/11

Всё работает на вашем компьютере: фраза пробуждения (Vosk), распознавание речи
(faster-whisper), ответы (Ollama + qwen3:8b), озвучка (голоса Windows).
Платные API и облако не используются; интернет нужен только один раз, чтобы скачать модели.

Целевое железо: i5-10400F, RTX 3060 12 ГБ, 16 ГБ ОЗУ.

## Как это работает

```
микрофон ─► wake_word (Vosk, «Джарвис») ─► audio_input (запись до паузы, VAD)
        ─► speech_recognition (Whisper small, GPU → CPU) ─► assistant
        ─► llm (Ollama localhost) ⇄ tool_registry ─► windows_control / memory
        ─► text_to_speech (SAPI5) ─► динамики
```

| Модуль | Назначение |
|---|---|
| `jarvis/wake_word.py` | ожидание «Джарвис» (Vosk с грамматикой из одного слова, CPU) |
| `jarvis/audio_input.py` | захват с микрофона в память, определение конца речи |
| `jarvis/speech_recognition.py` | faster-whisper `small`, откат на CPU при ошибке GPU |
| `jarvis/llm.py` | клиент Ollama (только localhost), ограниченная история |
| `jarvis/tool_registry.py` | реестр разрешённых действий и проверка аргументов |
| `jarvis/windows_control.py` | приложения, сайты, поиск файлов, системная информация, окна |
| `jarvis/memory.py` | SQLite: факты о пользователе и голосовые настройки |
| `jarvis/text_to_speech.py` | озвучка, прерываемая между предложениями |
| `jarvis/security.py` | аварийная остановка, подтверждения, антиповтор, сетевой фильтр |
| `jarvis/intents.py` | быстрые команды без LLM («открой блокнот», «который час», «погромче») |
| `jarvis/assistant.py` | логика диалога (без аудио — тестируется отдельно) |
| `jarvis/tray.py`, `jarvis/autostart.py` | значок в трее, автозапуск через папку «Автозагрузка» |
| `jarvis/main.py` | сборка компонентов и голосовой цикл |
| `jarvis/checks.py` | проверка зависимостей и моделей при запуске |

## Установка (Windows)

**Быстрый способ:** установите Python 3.11+ и Ollama, затем запустите `install.bat`.
Скрипт создаст окружение, поставит зависимости, скачает модели (спросив подтверждение) и проверит всё.
Запуск помощника: `run.bat`, текстовый режим: `run_text.bat`.

**Вручную:**

1. **Python 3.11+** с python.org (галочка «Add to PATH»).
2. **Ollama** с ollama.com, затем модель (~5.2 ГБ, около 6 ГБ VRAM):
   ```
   ollama pull qwen3:8b
   ```
3. Зависимости (~1.5 ГБ вместе с библиотеками CUDA для Whisper):
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Модели речи, около 520 МБ (Vosk ~45 МБ + Whisper small ~470 МБ). Скрипт покажет размеры и спросит подтверждение:
   ```
   python scripts\download_models.py
   ```
5. Русский голос: *Параметры → Время и язык → Речь → Добавить голоса → Русский*.

Память: Whisper small на GPU занимает около 1 ГБ, qwen3:8b около 6 ГБ, то есть 12 ГБ VRAM хватает с запасом.
Если GPU недоступен, Whisper автоматически работает на CPU (int8).
Ollama выгружает модель из VRAM после 5 минут простоя (`llm.keep_alive`).

## Запуск

```
python scripts\check_components.py          # проверить всё
python scripts\check_components.py --live   # плюс реальные пробы LLM, голоса и микрофона
python -m jarvis                            # голосовой режим
python -m jarvis --text                     # текстовый режим (без микрофона), удобно для отладки
```

```
python -m jarvis --tray                     # со значком в трее (цвет показывает состояние)
python -m jarvis --autostart on             # запускать при входе в Windows (off — выключить)
```

Значок в трее: синий — ждёт «Джарвис», зелёный — слушает, оранжевый — говорит, серый — микрофон выключен.
Щелчок по значку включает и выключает микрофон, в меню есть «Остановить» и «Выход».
Автозапуск кладёт `JARVIS.cmd` в папку «Автозагрузка» пользователя, права администратора не нужны.

В окне программы: **Enter** включает и выключает микрофон, **s + Enter** даёт аварийную остановку, **q + Enter** завершает работу.

## Голосовые команды

- «Джарвис» → короткий сигнал → команда. Можно говорить одной фразой: «Джарвис, открой блокнот».
  После ответа примерно 8 секунд можно продолжать без повторного «Джарвис».
- «Стоп», «хватит», «замолчи»: перебить помощника, пока он говорит.
- «Отмена»: отменить текущий диалог.
- «Стоп стоп», «Аварийная остановка», «Джарвис стоп»: немедленно остановить речь и отменить ожидающее действие.
- «Выключи микрофон»: микрофон выключается, включить его снова можно клавишей Enter.
- «Очисти память»: требует подтверждения.
- «Новый диалог»: сбросить историю беседы.
- «Заверши работу»: выход.
- Громкость и музыка: «погромче», «потише», «выключи звук», «пауза», «следующий трек».
- Примеры: «открой блокнот», «открой ютуб», «найди файл отчёт», «сколько свободно памяти»,
  «сверни окно телеграм», «запомни, что меня зовут Давид», «сделай речь быстрее».

## Безопасность

- Модель **не выполняет код**: никакого Python, PowerShell или shell от LLM. Она может только попросить
  вызвать инструмент из реестра `tool_registry`. Неизвестные инструменты, лишние аргументы, неверные типы
  и управляющие символы отклоняются.
- Приложения и сайты берутся **только из `config.toml`** (`[windows.apps]`, `[windows.websites]`).
  Запуск идёт без оболочки.
- Поиск и удаление файлов разрешены только в каталогах `windows.search.allowed_dirs`.
  Удаление идёт **в корзину**.
- Удаление файла, закрытие окна, смену настроек и очистку памяти нужно **подтвердить голосом**
  («подтверждаю»). Любой другой ответ или 20 секунд тишины отменяют действие.
- Повтор той же фразы в течение 4 секунд игнорируется. Выполняется не больше 12 действий в минуту
  и не больше 3 вызовов инструментов на реплику. Повторный одинаковый вызов прерывается как цикл.
- Во время своей речи помощник реагирует только на фразы перебивания («стоп», «хватит»).
  Остальное, включая эхо собственного голоса, отбрасывается.
- Все выполненные действия записываются в `data/actions.log` (без записи звука и без текста разговоров).
- Сетевые соединения из процесса разрешены только к `security.allowed_hosts` (localhost),
  загрузки Hugging Face отключены (`HF_HUB_OFFLINE=1`).
- Программа не требует прав администратора. Запускайте от обычного пользователя.
- Звук не записывается на диск. Микрофон можно физически отключить: помощник это заметит и остановится.

## Тесты

```
pip install -r requirements-dev.txt
python -m pytest
```

Тесты не требуют Ollama, микрофона и моделей: LLM, окна и корзина заменены фейками.
Тестами покрыты безопасность, реестр, управление Windows, память, клиент Ollama
(через локальный фейковый сервер), определение конца речи и логика диалога.
